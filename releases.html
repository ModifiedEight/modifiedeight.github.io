1.6.1 & 1.6.1.1 August 17, 2026

Classic:

* Added background music
* Fixed an issue with the D-pad size toggle
* Fixed an issue with yaw display
* Fixed various iOS bugs
* Fixed bugs related to the texture manager
* Added display of other players skins


New Additions:

* All changes from the classic version
* Normalized the placement of vertical and horizontal slabs. Horizontal slabs are now placed by clicking the center of the connecting block, while vertical slabs are placed by clicking on the sides
* Fixed an issue where connected slabs would not break separately
* Fixed an issue where connected slabs could not be dyed
* Added new flowers
* Added tall grass and large fern
* Added vine and lily pad
* Added seagrass
* Added functionality for sponges
* Completely revamped the new world generation
* Added village and desert temple generation
* Added the new swamp biome
* Different biomes now have different color palettes
* Added underwater swimming
* Added swimming and walking animations for the player
* Added plant animations
* Added dye crafting from flowers
* Added single-player commands: /tp, /locate, /list, /time set

1.3.0 June 16, 2026

* The client now has 2 modes: Modded and New Additions. The Modded mode adds new functionality, while New Additions adds new blocks and items. If you choose the Modded mode, you will have access to all new features except those related to new blocks and items.
* Added an option to make the old world type infinite in the world settings.
* Added an option to change the player's position coordinates in the world settings.
* Added an FPS counter.
* Added a Debug Screen.
* Added the ability to enable and disable fog.
* The render distance can now be increased even further.
* Added a switch between the old texture loading system (using the terrain-atlas) and the new one.
* Added a Marketplace: integrated downloading of maps and textures from https://mcpe-source.github.io/, as well as a map and texture manager. In the world manager, you can import worlds from archives, and in the texture manager, you can save and install textures from archives.
* Added Discord Rich Presence integration.
* Added the iron door to the creative inventory.
* Updated the colored bricks texture (thanks to mryoshi).
* Other changes
